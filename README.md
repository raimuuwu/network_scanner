# network_scanner
Simple network scanner CLI
Works on Linux and Windows

## Features:
- Displays network info
- Scans local network for hosts

## Usage
- "-i", "--info" -> display info
- "-s", "--scan" -> scan local network
- no parameters -> displays help

## Issues
